## Topics Covered

### 1. Python Lists

The notebook includes practice with the following methods and operations:

| Method or operation | Purpose |
|---|---|
| `extend()` | Adds multiple elements from an iterable to a list. |
| `sort()` | Sorts list elements in ascending order by default. |
| `reverse()` | Reverses the order of elements in place. |
| `insert()` | Inserts an element at a specified index. |
| `pop()` | Removes and returns an element. |
| `append()` | Adds an element to the end of a list. |
| `sum()` | Calculates the sum of numeric elements. |
| `del` | Deletes an element at a specified index. |

### 2. Python Sets

The notebook includes basic set operations using:

- **Union (`|`):** Combines the unique elements of two sets.
- **Difference (`-`):** Returns elements present in the first set but not in the second.

## Example

```python
numbers = [1, 6, 3, 9, 5, 6, 7]

numbers.extend([8, 9])
numbers.sort()

print(numbers)
```

Output:

```text
[1, 3, 5, 6, 6, 7, 8, 9, 9]
```
